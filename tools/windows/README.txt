BUILD DANGEROUS - for Windows
REVIVE8BIT - 2026 - VASPER

An Amstrad CPC game, with the emulator that runs it included.

TO PLAY
  Double-click BuildDangerous.exe. Nothing is installed: the first time, it unpacks the
  emulator and the game to %LOCALAPPDATA%\BuildDangerous (about 15 MB), then starts. The
  REVIVE8BIT screen comes first (10 seconds, or press SPACE), then the game loads.

  Windows may warn that the program is from an unknown publisher (it isn't signed):
  choose "More info", then "Run anyway".

KEYS
  Cursor keys or Q A O P   walk, climb stairs; Up jumps, Down ducks
  SPACE                    set off a trap / answer the phone / start / continue
  M                        sign off the room
  ESC                      pause
  L                        English / Greek (on the title screen)
  A joystick works too (Fire 1 = SPACE, Fire 2 = M, both together = pause).

  F1 opens the emulator's menu, F2 switches to full screen, F10 quits.

The manual: manual.pdf (English), manual_gr.pdf (Greek).

THE EMULATOR
  Caprice32, https://github.com/ColinPitrat/caprice32 - free software under the GNU GPL,
  version 2 (licences/Caprice32-GPL.txt); its source code is at that address. It includes
  the Amstrad CPC system ROMs, which Amstrad allows to be distributed with emulators.
